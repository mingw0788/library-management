# 三角色操作手册

本手册对应当前源码。首页在登录前显示登录引导；登录后展示馆藏预览、分类、在册及可借数量，可以直接搜索书名、作者或 ISBN，点击分类查看对应图书，也可进入本角色工作区。系统会重新核对登录账号是否启用、凭据是否仍有效，因此账号禁用或密码重置后，旧会话需要重新登录。

## 所有人共用的操作

在管理员提供的地址打开系统，输入分配的登录名和密码。首次登录或密码被重置后，系统会先要求修改密码。密码须为 12—64 个 Unicode 字符，且 UTF-8 编码不超过 72 字节；保存后当前会话退出，请用新密码重新登录。不要把密码写进书目简介、浏览器共享设备或普通消息。

点击“本人资料”可以修改允许本人维护的姓名；读者还可以修改联系方式。登录名、角色、账号状态和读者证号不能自行修改。完成操作后使用页面上的“退出登录”按钮。

首页与各业务页面顶部都有统一导航：读者可进入“我的借阅”和“我的预约”；馆员、管理员可进入借出、归还、借阅记录和馆藏管理。预约启用时才显示“我的预约”或“预约取书”；管理员另有工作人员账号及审计入口。首次登录仍须先完成改密。

首页图书预览按书名排序，最多展示 6 种，点击“查看全部图书”可打开完整目录。首页统计仅包含有效书目及其未注销副本；在册册数包含借出和预约保留的副本，可借册数仅计算当前可借副本。工作人员工作区的历史总数仍包含已归档书目和已注销副本，统计口径与馆藏首页不同。

目录以卡片展示书名、作者、分类和可借数量，点击书名查看详细资料及馆藏位置。手机上卡片和表单自动改为单列；借阅等宽表格可在表格区域内左右滑动查看。

目录提供 10/20/50/100 种的每页数量选择；通过已有链接进入的其他合法页大小也会保留。检索后可点击条件标签的 × 单独清除关键词或分类，保留其余筛选、排序和每页数量并回到第一页；“重置全部”恢复默认目录。

从目录书名进入详情后，“返回检索结果”保留关键词、分类、排序、每页数量和页码；直接打开详情时返回默认目录。此浏览位置保留针对目录与详情之间的 GET 导航，预约提交仍按原流程返回该书详情。详情顶部显示可借/在册数量，可跳到馆藏位置；工作人员另有带当前书名的借出搜索入口，读者仍需到馆办理。下方可浏览同分类图书。返回地址固定为站内目录，异常浏览参数会回退到默认目录。

目录 `/catalog` 对已登录用户开放，可按书名、作者或 ISBN 搜索、按分类筛选并查看书目详情。详情中的可借数量来自实体副本状态。读者不能在线办理借出或归还。预约扩展支持排队、72 小时到书保留、馆员核验取书以及超时自动释放；系统默认和 dev profile 关闭，prod profile 配置已启用但尚未部署。

## 管理员

管理员工作区是 `/admin`。管理员可以管理工作人员账号、查看关键操作审计，也可以进入工作人员工作区处理日常馆藏和借还业务。

1. 打开“工作人员账号管理” `/admin/accounts`，创建管理员或馆员账号。初始密码需要通过受控方式交给本人；本人首次登录后必须改密。管理员可重置工作人员密码或禁用账号，但不能停用最后一名有效管理员。
2. 通过工作人员工作区的“读者管理” `/staff/readers` 创建读者。需填写唯一登录名、唯一读者证号、姓名和符合规则的初始密码；联系方式可选。创建后安全地交付初始密码。管理员和馆员均可维护读者资料、重置密码和禁用读者。
3. 进入 `/staff/categories` 维护分类；被书目引用的分类不能删除。进入 `/staff/books` 建立书目；需要先有分类。ISBN 可留空，填写时会校验格式和校验位。
4. 进入 `/staff/copies` 为每一册实体书登记一条副本记录及唯一条码。数量由副本状态汇总，不要手工修改库存。
5. 进入“关键操作审计” `/admin/audit` 查询成功的关键业务操作。普通馆员和读者没有该页面权限。

## 馆员

馆员工作区是 `/staff`。馆员可以检索目录、管理读者、分类、书目和实体副本，并办理全馆借还和查询借阅记录；不能创建、禁用或重置工作人员账号，也不能查看完整审计查询页。

日常建藏顺序是：先在 `/staff/categories` 建分类，再在 `/staff/books` 建书目，最后在 `/staff/copies` 按册登记条码和馆藏位置。每册需要独立条码。只有可借副本能注销；仍有未注销副本、未还借阅时不能归档书目。历史记录通过注销或归档保留，不物理删除。

读者、书目和副本管理列表每页显示 10 条，列表上方和下方显示总条数、当前页及翻页入口。读者可按姓名、证号或登录名查找，并筛选启用/禁用；书目可按书名、作者或 ISBN 查找，并筛选有效/归档；副本可按条码或书名查找，并筛选可借、借出中、预约保留或已注销。默认包含全部状态，历史记录仍可检索。关键词最多 100 个字符，百分号和下划线按普通文字查找。

点击“查询”从第一页显示新筛选结果；翻页会保留关键词和状态，“重置筛选”返回全部状态第一页。新增、修改、归档、注销或读者账号操作后保留当前筛选与页码；如果操作后该页已不存在，系统显示最后一页。保存失败时保留表单错误和安全回填内容，密码不会回填。没有匹配结果时显示空列表提示，书目和副本的数量统计仍计算该书目的全部副本。

办理借出时打开 `/staff/loans/checkout`，依次完成以下操作：

1. 按姓名或读者证号搜索并选择读者。仅显示启用的读者。
2. 按书名、作者或馆藏条码搜索并选择一册实体副本，也可以扫描条码后搜索。仅显示有效书目的可借副本；选择时核对条码和馆藏位置。同一书目的不同副本分别显示。
3. 在“核对借阅信息”区核对读者姓名、证号、书名、作者、条码、位置和预计应还日期，勾选“已核对读者证及实体书条码”，点击“确认借出”。搜索和选择不会办理借出，重新搜索任一侧会保留另一侧的有效选择。每次搜索最多显示 20 条，结果较多时补充关键词。

核对区会提示逾期、额度或同书未还等限制；所选账号被停用、副本已不可借时，需要重新选择。系统按提交时的数据库状态重新检查读者和馆藏资格：默认最多同时借 5 册、每册借期 14 天；有未还逾期或已持有同一书目的副本时不能再借。实际应还日期以成功提示为准。借出成功后，副本变为“借出中”。

办理归还时打开 `/staff/loans/return`，输入借阅编号或馆藏条码之一并确认。系统记录归还时刻和办理人，并将副本恢复为“可借”。禁用读者的未还图书仍可归还；重复归还不会重复改变状态。

在 `/staff/loans` 可筛选、分页查看全馆当前借阅和历史记录；逾期按上海本地日期计算，应还当天不算逾期。工作区首页统计全馆书目、副本、当前借阅和逾期数量。

## 读者

读者工作区是 `/reader`。读者可以在 `/reader/loans` 查看本人当前借阅、历史借阅和逾期情况，也可以在 `/catalog` 检索书目。本人资料、密码入口分别为 `/account/profile` 和 `/account/password`。

用读者账号登录后，馆藏首页 `/` 和读者工作区 `/reader` 都显示“借阅与取书提醒”：

- **逾期未还**：应还日期早于今天且仍未归还的记录，显示应还日期及逾期天数；应还当天不算逾期。
- **近期应还**：今天以及未来 3 天（含第 3 天）应还的未还记录，显示“今天应还”或剩余天数。可点击“查看借阅及续借资格”进入本人借阅记录，是否允许续借以该页及提交时检查为准。
- **预约待取**：预约功能启用时显示仍在保留期内的本人待取图书及截止时间。请在截止时间前到馆，由馆员核验办理；恰好截止或已经超时的预约不再计入待取提醒。

提醒日期和时间按系统业务时区计算（当前为 Asia/Shanghai），每类显示总数并最多列出 5 项，优先列出最早应还或最早截止的记录，更多记录可进入“我的借阅”或“我的预约”查看。已归还图书、排队中的预约和已结束预约不会出现在对应提醒中。刷新页面会重新查询最新状态；浏览提醒不会办理归还、续借或取书。没有待办时显示空状态，缺少读者档案时提示联系馆员完善资料。

读者不能查看或修改他人的借阅，不能自行办理借出或归还。需要借还时请携实体书到馆，由管理员或馆员操作。在“我的借阅记录”中，符合条件的本人未还记录会显示“续借 14 天”按钮。每条借阅最多续借一次；账号须启用，当前借阅未归还且未逾期，本人也不能有其他逾期未还记录。续借从原应还日期增加 14 天；应还当天仍可续借，逾期次日起不能续借。启用预约的系统可在 `/reader/reservations` 查看本人队列；到书后页面显示 72 小时截止时间，须由馆员在 `/staff/reservations` 核对读者证号并办理。若读者逾期或已达到借阅上限，馆员取书会被拒绝，保留仍保持到截止；截止后系统每分钟扫描，并在取书请求中实时检查，到期即释放副本并按队列继续分配。取消或停用账号也会释放副本。预约功能在 prod profile 配置启用，尚未部署；默认和 dev profile 关闭。

预约功能启用时，用读者账号打开“馆藏目录”，搜索并点击书名，在详情页的“预约这本书”区域提交。系统自动关联当前图书，无需填写书目编号；提交结果仍显示在该书详情，可点击“查看我的预约”查看本人队列或取消预约。“我的预约”页面提供目录入口。

图书有可借副本时，页面提示到馆借阅；没有可流通副本时暂不能预约。本人已排队或已有到书保留时，会显示对应状态并隐藏重复预约按钮。逾期未还、达到借阅上限、已借有同一书目或缺少读者档案时，页面会说明原因。提交时系统会重新核对库存和资格，页面展示后发生变化也可能导致提交被拒绝。工作人员不显示读者预约操作；功能关闭时不显示预约区域。

## 管理工作区图表与快捷操作

管理员进入 `/admin`，馆员进入 `/staff`，可查看六项全馆统计及两张分布图。副本图区分可借、暂不可借和已注销；暂不可借包含借出及预约保留。借阅图区分未逾期和逾期未还，按上海日期计算，应还当天仍未逾期，已还记录不计入。图例同时显示文字和数量；没有副本或未还记录时显示对应空状态。统计随页面刷新更新。

点击书目、副本、可借副本和当前借阅卡片可进入对应记录，可借及未还入口已带筛选条件。快捷操作提供借出、归还、读者、书目及副本管理，预约功能启用时增加取书入口；管理员额外看到工作人员账号和操作审计。入口打开表单或列表，实际业务仍需核对后提交；读者不会看到管理看板。

## 借阅、预约列表与操作反馈

借阅列表默认显示“当前未还”，查看历史请选择“已归还”或“全部记录”。列表显示符合条件的总数，可按借出日期筛选并重置条件；日期起止错误会显示具体原因。续借后保留原状态、日期和页码；每笔借阅最多续借一次，当前逾期或本人其他借阅逾期时不能续借。实际操作仍由服务器重新核验。

手机上的借阅和预约记录按卡片展示，每项附有名称；桌面保留表格。预约提交和保留截止时间按页面标注的业务时区显示，默认 Asia/Shanghai。待取预约突出保留截止，结束的预约不会继续显示“请取书”；可点击书名返回详情。

取消预约、续借和工作人员办理取书前弹出确认；取消确认不会提交。提交按钮显示处理中并暂时禁用，避免连续点击；服务器仍负责权限、状态及并发校验。若关闭浏览器 JavaScript，原生表单仍可用，以上浏览器确认与防重复点击增强不生效。浏览器返回页面后恢复按钮。

归还成功表示借阅已结束、副本状态已更新；存在排队预约时，副本可能立即转为预约保留，可借数量不一定增加。使用键盘 Tab 可显示“跳到主要内容”，链接、按钮与输入框均提供焦点边框。

## 常见问题

| 现象 | 处理方式 |
|---|---|
| 页面提示登录名或密码错误 | 检查输入法、大小写和空格；账号可能已被禁用，联系管理员核对或重置。系统对未知、错误密码和禁用账号使用相同提示。 |
| 登录后又回到登录页 | 账号可能被禁用、密码已重置或会话已失效；重新登录。若持续发生，联系管理员检查账号状态。 |
| 页面提示没有权限 | 确认当前账号角色。只有管理员可管理工作人员和查看审计，工作人员业务页仅对管理员/馆员开放，读者页面仅对读者开放。 |
| 借出失败 | 核对读者证号和条码，确认副本可借、读者未被禁用、未超额度、无逾期且未持有该书目的其他副本；竞争操作也可能使刚才显示的状态变化。 |
| 归还失败或显示已归还 | 核对条码或借阅编号；如记录已经归还，无需再次提交。 |
| 表单显示字段错误 | 按字段旁的中文说明修正。密码不会自动回填；重复登录名、证号、ISBN 或条码会被拒绝。 |
| 服务无法打开 | 联系系统维护人员检查应用和 MySQL 服务；不要在业务库中手工删表或改状态。 |

管理员和维护人员的启动、数据库、日志与恢复步骤见[开发与运行说明](development-guide.md)及[部署与恢复说明](deployment-recovery.md)。
