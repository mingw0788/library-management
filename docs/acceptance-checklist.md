# 需求与验收证据清单

本清单将[需求基线](requirements.md)的每一项映射到实现任务和可查的验收记录。任务详情、实际命令、用例结果和限制以[开发进度](progress.md)为准；本清单不把计划中的验收当成已执行结果。

状态含义：**已验收**表示有对应实测记录；**部分验收**表示仅完成注明的内部或测试范围；**未实现/未选择**表示该能力没有实现或尚未获授权，不能对用户承诺已提供。
