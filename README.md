# 图书管理系统

这是一个中文、服务端渲染的单馆图书管理系统。基础计划 T01—T24 和可选扩展 X01—X04 已完成：读者可为本人符合条件的借阅续借一次，也可排队预约、接收 72 小时到书保留并由馆员核验取书。默认和 dev profile 关闭预约；test 与 prod profile 启用。生产配置已就绪，但系统尚未部署。项目使用 Java 21、Spring Boot 4.1.1、Maven Wrapper 3.9.16 和 MySQL 8.0.44。

新用户请先阅读[三角色操作手册](docs/user-guide.md)。开发者可按[开发与运行说明](docs/development-guide.md)构建、测试、启动和初始化首位管理员；环境、数据库和部署约定分别见[环境基线](docs/environment.md)、[数据库结构](docs/database.md)及[部署与恢复说明](docs/deployment-recovery.md)。每项需求的状态和验收证据见[验收清单](docs/acceptance-checklist.md)与[开发进度](docs/progress.md)。

当前源码已完善首页和导航：登录后首页显示真实馆藏、分类、在册及可借数量，可直接搜索图书；各业务页面按账号角色提供工作区、借还和预约入口。预约启用时，符合条件的读者可在图书详情直接预约，页面自动关联当前图书并提示排队、保留或可借状态，无需输入书目编号。全部本地改进已收录到下方完整版本交付包。

包含全部扩展及 U01—U08 改进、时间精度修复的运行包、完整源码快照和启动说明见[完整版本地交付](docs/delivery.md)。本次收尾通过 141 项回归和三角色浏览器检查，详情见[本地版本最终验收](docs/final-local-acceptance.md)。包内同时提供既有 V12 恢复及空库初始化报告。交付包保存在本机忽略目录，不随 Git 源码分发；历史包保留供核对。

当前源码的借出页面支持按姓名或证号搜索读者、按书名/作者/条码选择可借副本，并在办理前核对读者、实体书和预计应还日期。详情见操作手册的馆员部分。

读者、书目和副本管理列表支持关键词、状态筛选及每页 10 条的数据库分页，翻页及操作后保留筛选条件和页码。

读者登录后的首页和读者工作区提供逾期未还、今天及未来 3 天应还、预约待取提醒，仅查询本人记录，按业务时区显示日期与取书截止时间。

管理员和馆员工作区新增副本可借情况、未还借阅逾期情况图表及常用业务快捷入口；统计卡片可跳转到相应管理记录，账号与审计入口仅对管理员显示。

目录筛选可单独清除关键词或分类，从检索卡片进入详情再返回时保留条件、排序和页码。详情集中展示库存、馆藏位置和借书指引，工作人员可带书名进入借出搜索。当前本机运行完整优化版本，新交付包与运行 JAR 一致。

借阅和预约记录统一状态提示，手机显示逐条卡片；预约时间按配置的业务时区显示。续借后保留筛选与页码，取消预约及办理取书前确认，提交期间防止重复点击。全站提供键盘跳转和焦点提示。

## 本机开发

在 Windows PowerShell 中进入项目目录，先载入只保存在本机的专用测试库和开发库连接，再运行完整验证：

```powershell
Set-Location 'E:\AI\图书管理系统\library-management'
. .\scripts\set-local-db-env.ps1 -Profile test
. .\scripts\set-local-db-env.ps1 -Profile dev
.\mvnw.cmd verify
```

验证会连接隔离的 `library_test` 和 `library_dev`，运行真实 MySQL 回归并生成可执行 JAR。首次构建需要联网下载固定 Maven Wrapper 和项目依赖。完整的首次配置、空库迁移、管理员初始化和常见错误处理步骤见[开发与运行说明](docs/development-guide.md)。

测试通过后启动本机开发实例：

```powershell
. .\scripts\set-local-db-env.ps1 -Profile dev
.\mvnw.cmd spring-boot:run
```

浏览器访问 <http://localhost:8080/>。应用默认只监听本机地址；停止时在启动窗口按 `Ctrl+C`。`.local/mysql-connection.json`、本机密码、日志、备份及构建产物都不应提交到 Git。

## MVP 范围

系统包括角色授权、账号和读者档案、分类/书目/副本管理、目录检索、馆员办理借出和归还、借阅查询、审计与统计。默认最多同时借 5 册、借期 14 天；读者可按规则为本人借阅续借一次。预约在到期或实时取书检查发现超时后释放副本并按 FIFO 分配，重复扫描安全；prod profile 已启用此扩展，dev 与默认 profile 仍关闭。

项目尚未发布到公网或生产环境；T22 的独立数据库恢复演练和当前部署前提见[部署与恢复说明](docs/deployment-recovery.md)。
